极简三步，零学习成本

保留你在 Windows 养成的直觉，同时完全遵守 macOS 访达的安全移动机制。

1

选中文件按 ⌘X

FinderCut 在后台转换为安全复制并记录剪贴板版本，同时呈现原生液态玻璃 HUD 与轻微提示音。

2

切到目标文件夹

文件在真正粘贴前保持原地不动。中途按 Esc 取消，或复制了其他文字/文件时，待移动状态会自动失效。

3

按 ⌘V 完成原生移动

自动改写为访达原生的 ⌥⌘V（将项目移到这里），保留系统进度条、冲突提示与 ⌘Z 一键撤销。

克制，但把细节做到位

只解决访达缺少文件剪切这一个痛点，不常驻臃肿面板，不修改系统文件。

重命名与输入框零误触

精准识别文件重命名、搜索框、标签输入框、密码框、弹出表单及 Quick Look 预览，按下 ⌘X 原样放行文字剪切。

复用访达原生引擎，零注入

不注入 Finder 进程，无需关闭 SIP。跨磁盘移动、同名替换询问、权限提示和 ⌘Z 撤销全部原汁原味。

液态玻璃 HUD、提示音与隐藏图标

macOS 26+ 原生液态玻璃（Liquid Glass）HUD（旧版自动适配圆角毛玻璃），搭配轻微提示音与可隐藏菜单栏图标，全部独立开关。

多语言支持，菜单栏实时切换

原生适配简体/繁体中文、英语、日语、韩语等多国语言并持续扩展，默认匹配系统语言，支持免重启即时切换。

兼容非 QWERTY 键盘布局

通过系统输入源动态解析 X / C / V 键位，Dvorak、Colemak 或多语输入法下依然准确响应。

单实例与唤醒自愈

纯原生 Swift 编写零第三方依赖，防多开重复拦截，系统休眠唤醒或权限变化时自动检测并重连监听。

三步开启「辅助功能」权限

首次使用只需在系统设置中勾选一次，即可在访达无感使用 ⌘X / ⌘V。

1

运行 FinderCut

将 FinderCut.app 拖入「应用程序」并打开；首次运行会自动提示，也可点击菜单栏里的「打开“辅助功能”设置…」。

2

进入「隐私与安全性 → 辅助功能」

在系统设置左侧边栏点击「隐私与安全性」，向下找到并进入「辅助功能」权限列表。

3

打开 FinderCut 开关

勾选启用 FinderCut 后，程序会在 1.5 秒内自动检测生效，无需重启即可开始使用。

常见问题

为什么需要授予「辅助功能（Accessibility）」权限？
为了在访达中监听 ⌘X / ⌘V 并判断当前焦点是否处于文件名输入框、搜索框或密码框，FinderCut 需要系统“辅助功能”权限。所有操作均在本地完成，不联网、不读取或上传任何剪贴板隐私。
隐藏菜单栏图标后，怎么再打开菜单调整设置？
只需像平时启动软件一样，通过聚焦搜索（Spotlight）、启动台或在「应用程序」里再次双击打开 FinderCut，运行中的实例就会自动重新显示菜单栏图标并展开菜单。
支持哪些 macOS 版本与芯片？
支持 macOS 13.0 Ventura 及以上系统，当前提供 Apple Silicon（arm64）原生版本。
